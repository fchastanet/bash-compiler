This section holds archived copies of external articles that this documentation relies on, kept so the references stay
reachable if the original sources disappear. Check the sidebar for the list of archived pages.

{{% /pageinfo %}}

## 1. How these archives are handled

Every backup page credits the original author, links to the original source, and shows both the original publication
date and the backup date. Archived pages carry a `noindex, nofollow` robots meta tag so that search engines index the
original article rather than this copy.

If you are an author and would like a page removed, please
[open an issue](https://github.com/fchastanet/bash-compiler/issues).
